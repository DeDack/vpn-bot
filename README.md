# abc-vpn

Telegram-бот и control plane для VPN-сервиса на базе Remnawave. Проект управляет пользователями, подписками, платежами и устройствами, а Remnawave отвечает за VPN-доступ.
Используйте AI для помощи с настройкой, так как инструкция может требовать уникальных настроек на сервере. 

Этот проект можно использовать в коммерческих целях, в нем реализован весь необходимый для этого функционал.
Так же описан алгоритм для развертывания main-сервера управления нодами на разных серверах, и функционал для работы на мобильном интернете.
## Возможности

- регистрация через Telegram и пробный период;
- тарифы, продление подписки и платежи через Platega;
- денежная реферальная программа с внутренним балансом и журналом операций;
- полная и частичная оплата подписки с реферального баланса;
- управление устройствами и лимитами HWID;
- синхронизация пользователей и подписок с Remnawave;
- рекламные кампании и аналитика источников;
- сегментированные рассылки с очередью, повторами и восстановлением после рестарта;
- административная панель;
- лендинг, политика конфиденциальности и условия использования.

## Стек

Java 21, Spring Boot 3, Spring JDBC, PostgreSQL, Liquibase, Maven, Docker Compose, Telegram Bot API, Remnawave и Platega.

## Быстрый запуск

1. Скопируйте пример конфигурации:

   ```bash
   cp .env.example .env
   ```

2. Задайте собственные значения в `.env`. Для первого локального запуска можно оставить Telegram и платежи выключенными. Не коммитьте `.env`.

3. Создайте общую сеть для abc-vpn и Remnawave:

   ```bash
   docker network create remnawave-network
   ```

4. Соберите и запустите приложение:

   ```bash
   docker compose up -d --build
   ```

5. Проверьте состояние:

   ```bash
   curl http://127.0.0.1:8080/actuator/health
   ```

Liquibase применит миграции автоматически. Административная панель доступна по `/admin` после настройки `ADMIN_WEB_PASSWORD` и `ADMIN_WEB_SESSION_SECRET`.

## Запуск тестов

```bash
./mvnw clean test
```

PostgreSQL integration-тесты используют Testcontainers, поэтому для полного запуска нужен Docker.

## Production

Пример маршрутизации находится в `deploy/Caddyfile`. Перед использованием замените домены и проверьте имена контейнеров. Запросы Happ с заголовком `X-Hwid` направляются через abc-vpn для проверки подписки и лимита устройств, а обычное открытие ссылки остаётся на Remnawave Subscription Page.

Отдельная инструкция по установке панели Remnawave, Subscription Page и подключению нод: [README_REMNAWAVE.md](README_REMNAWAVE.md).

Храните токены Telegram, Remnawave, Platega, пароли PostgreSQL и административные секреты только во внешнем `.env` или в менеджере секретов. В репозитории реальных credentials нет.
