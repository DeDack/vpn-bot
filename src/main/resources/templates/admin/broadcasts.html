Новое сообщение

URL или callback

URL открывает внешнюю HTTPS-ссылку. Укажите полный адрес, например https://abc-vpn.example.com.

CALLBACK выполняет действие внутри бота. Доступные значения:

  • connect — открыть подключение VPN;
  • tariffs — показать тарифы;
  • return_bonus — активировать одноразовый бонус на 2 дня;
  • main — открыть главное меню;
  • invite — открыть приглашение друзей;
  • support — открыть поддержку;
  • documents — открыть документы.

Для шаблона «Возвратный бонус» обязательны CALLBACK return_bonus и сегмент «Trial истёк, VPN-трафика не было».

Оформление текста

Telegram поддерживает HTML-разметку. Например, <b>Антиглушилки</b> отобразится жирным. Также можно использовать <i>курсив</i>, <u>подчёркивание</u>, <s>зачёркивание</s>, <code>код</code> и <a href="https://abc-vpn.example.com">ссылку</a>.

Закрывайте все теги и обязательно проверяйте сообщение кнопкой «Тест администратору». Некорректный HTML Telegram не отправит.

Безопасность

Возвратный бонус начисляется только после callback пользователя. Отправка сообщения ничего не активирует.

Пользователи без достоверной исторической телеметрии отмечаются отдельно и не могут активировать бонус.
